# 地面单层网格实现文档（交接用）

目标：解决两个问题。

1. 角色的脚陷进地面、草地比树根高。原因是地面由多层网格叠成（底色、草地、沙地、山路砂石、岩石），为了避免重合闪烁，上面的层各抬高 0.15 到 0.42 米，于是草地高于 `terrainHeight`，而树、石头、角色都站在 `terrainHeight` 上。
2. 大片平地完全是平的，要改成弧线起伏的大土坡。

做法：地面改成一张网格，按真实地形高度只画一层，用自定义 shader 在像素里混合几种贴图。没有叠层，所以不需要抬高，也不会闪烁。

## 3. 起伏土坡（WorldGen.ts）

`rollingHills(wx, wz, n, relief)` 加在 `baseHeight` 上：

- 噪声：`fbm(wx/70, wz/70, 2, SEED+5400)`，波长约 70 米，经过 `smoothstep(0.3, 0.75, f)`，坡顶圆、坡脚缓。
- 高度：最多 `HILL_HEIGHT = 5` 米，再乘地貌的起伏倍数 `relief`。
- 只抬高不压低。离水岸近的地方（`n` 在 `SAND_NOISE` 到 `SAND_NOISE + 0.06` 之间）逐渐压平，所以水岸线、桥头和水面不变。
- 格子类型由 `terrainNoise` 判定，和高度无关，所以不会改变哪里是水、沙地、草地。

## 4. 地面网格（GroundMesh.ts）

### 4.1 顶点数据

每个顶点带：

| 数据 | 存放位置 | 含义 |
|---|---|---|
| 位置 | POSITION | 真实地形高度，不抬高 |
| 法线 xyz | NORMAL0 | 平滑法线 |
| 岩石权重 | NORMAL0 的 w | 底层用岩石贴图（1）还是砂石贴图（0） |
| 草地颜色 + 草地 alpha | COLOR0 | alpha = 0.5 + 0.5 × 草地权重 |
| 沙地颜色 + 沙地 alpha | CUSTOME0（`a_Ground0`） | 同上 |
| 底层颜色 + 山路 alpha | CUSTOME1（`a_Ground1`） | 底层：道路砂石、水底或山体岩石 |
| UV | TEXCOORD0 | 块内坐标（米），shader 里按各贴图边长换算 |

顶点格式压缩到 36 字节：法线用 `nbyte4`，三组颜色用 `ubyte4`。引擎不支持这两种格式时退回全 float，共 88 字节。

`CUSTOME0`、`CUSTOME1` 的属性位置是 12、13，和引擎 GPU 实例化用的 `a_SimpleTextureParams`、`a_LightmapScaleOffset` 重复。地面不用实例化，所以在地面 shader 的属性表里删掉了这两个。

### 4.2 shader 合成

shader 复用 BlinnPhong 的 include（光照、雾、输出变换都和原来的材质一致）。像素里从下往上合成：

1. 底层：`底层颜色 × mix(砂石贴图, 岩石贴图, 岩石权重)`
2. 沙地
3. 草地
4. 山路砂石

每一层的覆盖度是 `smoothstep(0.48, 0.52, 顶点alpha × 贴图alpha)`。这和原来的 alpha 测试条件（≥ 0.5）一致，贴图 alpha 里的噪声仍然产生参差的边缘，只是阈值两边留了一点软过渡。

岩石贴图在 shader 里按法线投影：缓坡从上往下投影，陡坡投影到侧面，悬崖上的纹理不会被拉长。原来 CPU 端的 `rockUVMode` 因此删掉了。

顶点颜色在顶点 shader 里做 `pow(2.2)`，从 gamma 空间转到线性空间，和引擎处理 COLOR0 的方式一样。

### 4.3 shader 注册

`ensureGroundShader()` 用 `Shader3D.add` 在代码里注册，没有 `.shader` 资源文件。是否注册过用模块内的 `registered` 标记判断，**不能用 `Shader3D.find`**：LayaAir IDE 替换了 `find`，在资源库里找不到同名 shader 时会注册一个占位 shader 并返回它，同时打出 `shader not found` 警告。

## 5. ChunkRenderer 的构建流程

`buildSteps` 里只剩一个 `GroundBuilder`（`ground`），每个格子调用一次：

- 平地格子 `flatCell`：4 个顶点、2 个三角形，相邻格子共用顶点（`coarseIndex`）。
  - 草地颜色 `VGR/VGG/VGB`、草地 alpha `AG`。
  - 沙地颜色 `VSR/VSG/VSB`（新增，地貌沙色 × 逐格深浅）、沙地 alpha `AS`。
  - 底层 `underAt`，按周围 4 格取，优先级：道路（砂石）> 山体（岩石，岩石权重 1）> 水和桥（水底）> 沙地 > 草地。
  - 山路 alpha 取 `TA`。
- 山体格子 `mountainCell`：细分网格，每格 2×2 个四边形，顶点数据来自 `FH/FNR/FRC/FGC/FAG/FTA`，新增沙地 `FSC/FAS`。岩石权重固定为 1。

平地和山体交界：交界顶点的起伏权重 `DW` 是 0，所以高度、坡度都等于 `H`、`GX/GZ`。平地一侧用 `rockColorAt` 按同一公式算岩石颜色，交界处高度和颜色都一致。

桥格子下面仍画地面（底层是水底颜色），桥面另用 `plank` 层画。

### 5.1 图层

`TerrainLayer` 现在是 `ground | base | plank | granite | strata | foliage | bark | leafcard | pine`。原来的 `grass`、`sand`、`rock`、`gravel`、`trail` 已删除。
