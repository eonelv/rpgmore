# 关卡编辑指南

本文说明如何在 LayaAir IDE 里查看程序生成的世界、摆放刷怪点、添加怪物种类，以及游戏内小地图的用法。

适用版本：LayaAir 3.4.2。

---

## 1. 基本概念

| 概念 | 说明 |
|---|---|
| 格子（Cell） | 2 米 × 2 米，寻路和地形类型的最小单位 |
| 块（Chunk） | 32 × 32 格 = 64 米 × 64 米，加载、卸载、刷怪都以块为单位 |
| 块坐标 | `块 X = floor(世界 X / 64)`，`块 Z = floor(世界 Z / 64)` |
| 种子（SEED） | [WorldConfig.ts](../src/world/WorldConfig.ts) 里的 `SEED`。种子不变，世界每次都一样 |
| 出生点 | 大区 (0, 0) 的主干道交汇处（`spawnPoint()`），当前种子下约为世界坐标 (-99, 75) |

世界是确定性生成的。在编辑器里看到的地形，就是游戏里的地形。

> **注意：修改 `SEED` 会让整个地形变掉，已经摆好的刷怪点可能落进水里或石头里。** 正式摆放内容前先定好种子，之后不要再改。

---

## 2. 在 IDE 里预览地形

1. 打开 `assets/Scene.ls`。
2. 在层级面板中选中 `Scene3D` 下的 **WorldPreview** 节点。
3. 在属性面板里调整：

| 属性 | 作用 | 建议值 |
|---|---|---|
| 中心块 X / 中心块 Z | 预览区域的中心块 | 想编辑哪片区域就填哪里 |
| 半径（块） | 中心块向外显示几块。半径 3 = 7×7 块，约 450 米见方 | 2~4 |

改完属性后，场景视图会自动重建预览。

- 黄色竖线和十字是玩家出生点。
- 预览出来的地形节点不会出现在层级面板里，也不会保存进场景文件。
- 游戏运行时 WorldPreview 不起作用，地形由 `ChunkManager` 按玩家位置流式加载。
- 世界是程序生成的，没有边界，所以预览只能显示一部分。半径最大为 12（25×25 块，1600 米见方）。
- 预览从中心逐圈向外分帧生成，半径大时要等几秒才出全；离中心超过 3 块的地方用简化版网格（植被较粗）。
- 半径越大 IDE 越卡，摆放内容时建议调回 2~4。

**换一片区域编辑**：例如要在世界坐标 (640, -320) 附近放内容，先算出块坐标 (10, -5)，再把中心块填成 10 和 -5。

## 3. 摆放刷怪点

### 3.1 新建刷怪点

1. 在层级面板的 `Spawns` 节点下新建一个 **Sprite3D**。节点放在任何层级都可以，放在 `Spawns` 下只是方便管理。
2. 给节点起一个**唯一的名字**，例如 `wolf_den_north`。以后任务系统会用这个名字引用刷怪点。
3. 在属性面板里点"添加组件"，选择 **SpawnPoint**。
4. 在场景视图里把节点拖到想要的位置。

只有节点的 X 和 Z 坐标会生效，高度会自动贴地，Y 可以随便填。

### 3.2 属性

| 属性 | 说明 | 范围 |
|---|---|---|
| 怪物种类 | 下拉框，选项来自 `UnitDefs.ts` | — |
| 数量 | 生成几只 | 1~30 |
| 半径（米） | 生成范围，也是怪物平时闲逛的范围 | 1~60 |
| 清除所在块的随机怪 | 勾选后，刷怪点中心所在的块不再刷野外随机怪 | 默认勾选 |

### 3.3 场景视图里的标记

- **白色圆圈**：生成和闲逛的范围。
- **中心竖线**：刷怪点中心，上端是怪物种类的颜色。
- **彩色短竖线**：每只怪物的实际出生位置。

出生位置由刷怪点坐标和怪物序号算出，编辑器和游戏用的是同一个函数（`spawnPosition`），所以看到的位置就是游戏里的位置。如果短竖线比"数量"少，说明有几只附近找不到可走的格子，需要把刷怪点挪到开阔一点的地方。

### 3.4 摆放注意事项

- **不要放在水里、大片岩石或密林中间。** 怪物出生在离目标点 4 格以内最近的可走格子上，找不到就不生成。
- **刷怪点的范围可以跨越块的边界**，但怪物是在**中心所在的块**加载时生成，块卸载时回收。玩家离开约 3 块（约 190 米）后怪物会被回收，回来时重新生成。
- **"清除所在块的随机怪"只影响中心所在的那一块**，范围覆盖到的相邻块仍然会刷野外随机怪。
- **同一个块里可以放多个刷怪点**，只要其中一个勾选了"清除"，整块的随机怪就会被关掉。
- **想临时停用一个刷怪点**，把组件的启用勾选框关掉即可，运行时会被跳过。

### 3.5 运行时如何生效

游戏启动时，`Main` 会递归扫描整个 Scene3D，把所有启用的 SpawnPoint 收集进 `SpawnRegistry`，并按中心所在的块建立索引。之后每当一个块加载，`MonsterManager.spawnForChunk` 会：

1. 生成这个块里所有刷怪点的怪物；
2. 如果这些刷怪点都没有勾选"清除"，再按种子生成 0~2 只野外随机怪。

HUD 第四行的"刷怪点 N"显示收集到的数量，可以用来确认摆放是否生效。

## 4. 添加新的怪物种类

编辑 [src/world/UnitDefs.ts](../src/world/UnitDefs.ts)，在 `UNIT_DEFS` 里加一行：

```ts
bear: { name: "熊", color: [0.45, 0.3, 0.2], chaseColor: [0.8, 0.2, 0.1], speed: 5, aggro: 15, leash: 30, size: 1.5 },
```

| 字段 | 说明 |
|---|---|
| 键名（如 `bear`） | 种类 ID，会保存进场景文件。**定下来后不要改名**，否则已摆放的刷怪点会找不到这个种类 |
| name | 编辑器下拉框里显示的名字 |
| color | 平时的颜色，RGB，每个分量 0~1。小地图上的点和范围圈也用这个颜色 |
| chaseColor | 追击时的颜色 |
| speed | 移动速度，米/秒。玩家是 7 |
| aggro | 玩家进入这个距离（米）开始追击 |
| leash | 玩家超出这个距离（米）放弃追击，应大于 aggro |
| size | 体型缩放，1 = 1 米见方的方块 |

保存后，SpawnPoint 的"怪物种类"下拉框会出现新选项。如果没出现，重新打开场景或重启 IDE。

找不到的种类 ID 会按 `imp`（野外随机怪）处理。`RANDOM_KIND` 决定野外随机刷出哪种怪物。

## 5. 小地图

| 操作 | 效果 |
|---|---|
| 默认 | 右上角 200×200 像素，显示玩家周围约 320 米 |
| M 键 | 切换到屏幕中央的大地图，显示约 1600 米范围；再按一次切回 |
| 左键点小地图/大地图 | 主角自动寻路到点击处对应的位置 |

图例：

| 标记 | 含义 |
|---|---|
| 蓝色箭头 | 玩家和朝向 |
| 彩色小点 | 怪物，颜色取自怪物种类 |
| 粉红色小点 | 正在追击玩家的怪物 |
| 彩色圆圈 | 刷怪点范围 |
| 黄色圆圈 | 寻路目标。超出地图范围时贴在边缘，指示方向 |
| 上方白色短线 | 北（-Z 方向） |
| 地图上的文字 | 区域名字。暖白色是有名字的固定区域，灰白色是远处的"东域""西北域"等 |

区域按 512 米见方的大区划分。出生点周围 5×5 个大区有固定的名字（按地貌从名字表里取，如明月湖、栖霞谷、瞭望坡），更远的地方按方位叫"某某域"。走进另一个区域时屏幕上方会出现大字提示。名字表和有名字的范围在 [src/world/Areas.ts](../src/world/Areas.ts) 顶部修改。

没去过的地方也会显示。砍树后只重画被修改的那一块。刚打开大地图时，地图会在几帧内逐步画完，这是有意为之，避免卡顿。

## 6. 常见问题

**IDE 里看不到地形**
- 确认 WorldPreview 节点和组件都是启用状态。
- 把"半径"改一下再改回来，触发重建。
- 如果仍然不显示，查看 IDE 的开发者工具控制台是否有报错。

**刷怪点的标记不显示，或拖动后不更新**
- 确认组件已启用。
- 标记在移动节点或修改属性后才会重画。

**游戏里怪物没出现**
- 看 HUD 的"刷怪点"数量是否正确。为 0 说明组件没挂上或被停用。
- 走到刷怪点附近（2 块以内）再看。块加载后怪物才会生成。
- 编辑器里如果短竖线数量少于设定，说明附近没有可走的格子。

**改了 SEED 之后刷怪点位置不对**
- 刷怪点保存的是世界坐标，地形变了它不会跟着变。需要在新地形上重新检查每个刷怪点。
